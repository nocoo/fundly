# 07 · 仪表盘

>
> 前置：[06-ARCH-UI.md](./06-ARCH-UI.md)

---

## 这一页干什么

仪表盘是登录后的第一屏，回答三件事：

1. 库里现在有多少基金
2. 净值覆盖到哪一天、有多少行
3. 类型分布长什么样

同时提供宏观大屏、基金浏览、收益比较与风险观察入口。市场 K 线在 `/market` 与有真实交易行情的基金详情中展示。

---

## 布局

使用 Basalt AppShell 与全站统一的研究卡片布局：

- 顶部四张摘要：全市场基金、历史净值记录、MVP 研究池、通过 4433 的基金数。
- 中部以基金类型分布为主，右侧排列研究入口，两栏等高。
- 底部按基金大类展示数量与占比条，点击进入带分类条件的基金列表。
- 页头统一展示最新净值日期，历史起点与采集时间放在小「i」中。

移动端摘要变为两列，图表、研究入口与分类依次纵向排列。

## 数据合同

页面直接消费 `/api/stats` 与 `/api/fund-types`，不再走 `emptyDashboard()` 占位快照。

| 状态 | 页面 |
|------|------|
| 加载中且还没有缓存 | 「加载中…」，指标显示 `—` |
| 请求失败 | 错误文案 + 重试；指标保持 `—`，不把故障显示成 0 |
| 成功且库为空 | 显示 `0` / 空区间，这是真实零数据 |
| 成功且有数据 | 四张指标卡 + 类型分布图 + 分类入口 |

| 字段 | 来源 | 口径 |
|------|------|------|
| 基金只数 | `fund_basic_info` | `COUNT(*)` |
| 净值行 | `fund_nav` | `COUNT(*)` |
| 净值区间 | `fund_nav` | `MIN(nav_date)` / `MAX(nav_date)` |
| 类型分布 | `fund_basic_info` | `GROUP BY fund_type`，图上取前 12；大类入口汇总所有细类 |
| MVP 研究池 | `flags.mvp` | `in_mvp_pool = 1` 的基金数 |
| 4433 | `flags.pass4433` | `pass_4433 = 1` 的业绩记录数 |

## 空态文案

接口失败：

- 说明：错误信息
- 动作：重试

库已接但零行：

- 指标为 `0`，未提供日期显示 `—`
- 显示类型空态，不绘制占位行情
