# 07 · 仪表盘

> `/` 的信息架构。数字来自 `/api/stats` 与 `/api/fund-types`。
>
> 前置：[06-ARCH-UI.md](./06-ARCH-UI.md)

---

## 这一页干什么

仪表盘是登录后的第一屏，回答三件事：

1. 库里现在有多少基金
2. 净值覆盖到哪一天、有多少行
3. 类型分布长什么样

它不是行情大盘，也不放个股 K 线。4433 过线数和失败抓取下钻留给以后。

---

## 布局

沿用 Surety AppShell：左侧 Sidebar，右侧浮动卡片。

```
┌─────────────────────────────────────────────────────┐
│ 面包屑：首页                                         │
├──────────────┬──────────────┬───────────────────────┤
│ 基金只数      │ 净值行        │ 净值区间               │
│  COUNT(*)    │  fund_nav    │  MIN → MAX(nav_date)  │
├──────────────┴──────────────┴───────────────────────┤
│ 类型分布柱状图（前 12）                               │
└─────────────────────────────────────────────────────┘
```

移动端三张指标卡改为单列。

## 数据合同

页面直接消费 `/api/stats` 与 `/api/fund-types`，不再走 `emptyDashboard()` 占位快照。

| 状态 | 页面 |
|------|------|
| 加载中且还没有缓存 | 「加载中…」，指标显示 `—` |
| 请求失败 | 错误文案 + 重试；指标保持 `—`，不把故障显示成 0 |
| 成功且库为空 | 显示 `0` / 空区间，这是真实零数据 |
| 成功且有数据 | 三张指标卡 + 类型分布图 |

| 字段 | 来源 | 口径 |
|------|------|------|
| 基金只数 | `fund_basic_info` | `COUNT(*)` |
| 净值行 | `fund_nav` | `COUNT(*)` |
| 净值区间 | `fund_nav` | `MIN(nav_date)` / `MAX(nav_date)` |
| 类型分布 | `fund_basic_info` | `GROUP BY fund_type`，图上取前 12 |

## 空态文案

接口失败：

- 说明：错误信息
- 动作：重试

库已接但零行：

- 指标为 `0` 和 `— → —`
- 先跑 `bun run fetch:list`，再 `bun run import:d1`
