# 15 · 选 ETF：配置、交易质量与产品比较

> 2026-09-06 规划；按本文实施并回填实际覆盖。前置版本 `v0.5.0` 已推送、发布并通过 Railway 部署。沿用 [12 · 选基体系](./12-FUND-SCREENING.md) 的问题导向和 [14 · 宏观大屏](./14-MACRO-IMPLEMENTATION.md) 的 Basalt 视觉。

## 目标与范围

从宏观环境找到资产方向，再选择能承载该方向的 ETF。ETF 选择同时考虑资产类别、持有成本、成交质量和净值风险；按条件取交集，不生成黑箱推荐分。ETF 与场外联接、LOF、REITs 分开，目录身份来自 `asset_type=fund-etf`。

第一期交付六个列表页面和一个独立详情页面。全目录支持浏览；能核验关联的基金支持成本和净值研究；完成场内行情采集的研究池支持交易质量和真实 K 线。每个视角给出实际有效覆盖，缺资料的标的仍能搜索进入详情。

## 已实测的数据能力

REST 主路径：Bun 原生 `fetch` → `https://fuyao.aicubes.cn`，服务端 `HITHINK_FINANCE_API_KEY` 通过 `X-api-key` 传入。契约见参考仓库 `personal/reference/Financial-API/docs/api/endpoints-fund.md`；公开说明见 <https://fuyao.aicubes.cn/docs/api-reference/overview/>。

本轮 ETF / 股票共 33 个探测案例，32 个业务成功；另一例股票公司行动返回 `3002`。无凭据原始响应保存在本机忽略目录 `output/selection-research-2026-09-06/`。以下为探测结果，不是新功能上线覆盖承诺。

| 数据 | 接口或本地表 | 实测与限制 |
|---|---|---|
| ETF 目录 | `/api/meta/tickers/list?asset_type=fund-etf&limit=10000` | 1,670 只，带交易所后缀 |
| 关联本地基金 | `fund_basic_info` | 同六位 code 后，去空白并大写 ASCII 的名称完全一致：1,614 只；其中费用 1,614、净值和风险各 1,576 只 |
| 场内快照 | `/api/fund/market/snapshot?thscode=...` | 单只请求；已有宏观观察池实测。没有 ETF 全市场批量快照能力 |
| 场内日 K | `/api/fund/market/historical` | `interval=1d`，单次窗口最多五年，无复权参数；只用真实 OHLC |
| 基金资料 | `/api/fund/profile/detail?fund_type=exchange&thscode=...` | 510300、510310、159919、513100、511010 成功；有管理人、成立日、管理/托管费；没有明确跟踪指数 ID |
| 五年净值 | `/api/fund/performance/nav?fund_type=exchange&range=fyear&nav_type=unit,adj` | 510300 / 513100 / 511010 返回 1,217 / 1,216 / 1,217 行；单位和复权净值分开 |
| 披露规模 | `/api/fund/financials/indicators?fund_type=exchange&thscode=...` | 三只分别 84 / 80 / 80 行，有 `asset_nav`、报告起止、披露日期 |
| 披露持仓 | `/api/fund/portfolio/holdings?fund_type=exchange&thscode=...` | 复用宏观适配器，披露持仓并非实时组合 |

本地基金净值当前截至 2026-08-20，宏观行情截至 2026-09-04。不同日期不能算折溢价。目录中同 code 但简称不同的 40 个候选不能直接自动关联；仅代码相同不够。沿用已核验的 `market_symbol_alias` 时保留其核验依据，其余等待进一步资料核验。

## 页面与交互

导航新增「选 ETF」组，默认收起非当前组，避免挤满侧栏；保留选基和宏观入口。

| 路由 | 名称 | 主要列与默认排序 |
|---|---|---|
| `/etfs` | 浏览 | 名称/代码、资产类、最新价、涨跌、披露规模、覆盖状态、行内曲线；代码升序 |
| `/select-etf/allocation` | 资产配置 | 资产类、方向标签、规模、选定周期净值收益/回撤；规模降序 |
| `/select-etf/liquidity` | 交易质量 | 当日成交额、20 日均成交额、当日价、同日折溢价、成交历史覆盖；20 日均成交额降序 |
| `/select-etf/cost` | 成本规模 | 管理费、托管费、两费合计、规模、规模报告期；两费合计升序 |
| `/select-etf/risk` | 收益风险 | 1/3/5 年净值收益、年化收益、最大回撤、年化波动、样本数；最大回撤升序 |
| `/select-etf/picks` | 条件精选 | 资产类 + 费用上限 + 规模下限 + 回撤上限 + 成交额下限的交集；规模降序 |
| `/etfs/:symbol` | ETF 详情 | 真实市场日/周/月 K、净值风险、费率规模、披露重仓与已核验基金档案链接 |

共同控件：搜索、资产类、方向（可用时）、1/3/5 年、有效数据开关、排序与翻页。`q/category/theme/years/sort/order/page` 及当前视角数值条件进 URL；分页 50，过滤变化归第一页。未知参数规范化，不给任意 SQL 字段；排序中的 null 永远最后，代码为稳定次序。精选可以逐项开关阈值，显示当前启用条件及筛出数；没有满足者显示真实空态。

资产类使用已核验基金类型归为境内权益、境外权益、固收、货币、其他、待核验；默认研究境内权益，浏览默认全部。方向标签允许以产品名称规则划分宽基、红利低波、行业主题，必须在 i 说明「名称分类」，不将规则结果当作经过核验的跟踪关系。跨资产类混排时说明风险不可直接比较，不把债券 ETF 与股票 ETF 的回撤排名称为同类排名。

详情入口保存完整来源 URL；浏览器前进后退和「返回交易质量」等按钮恢复筛选、页码。新 tab / 直接打开详情默认返回 ETF 浏览，不能继承上次股票或基金的来源。扩展 `list-origin` 和导航激活判断，ETF 详情只激活原 ETF 列表项。

## 金融口径

| 指标 | 公式 / 选择规则 | 空值与日期 |
|---|---|---|
| 持续费用 | `management_pct + custody_pct`，单位 %/年 | 两项都已知才相加，零费有效；名为「管理+托管费」，不称全部交易成本，不包含券商佣金/买卖价差 |
| 规模 | 优先最新已披露 `asset_nav / 1e8`，其次已核验本地 `scale_yi` | 同报告期取最新披露；保存报告日和披露日。profile 的无日期 `fund_scale` 不能冒充当日规模 |
| 总回报序列 | 优先扶摇 `adj_nav`；本地用已有 `buildTotalReturn(nav, dividends)` | 禁止以 `acc_nav` 比值或未复权市场价冒充净值总回报；来源和净值日期保留 |
| 周期收益 | 窗口末值 / 窗口基值 − 1 | 1/3/5 年按自然年向前，边界允许最近交易日（10 天内）；历史不满周期为 null |
| 年化收益 | `(末值/基值)^(365.25/实际天数) − 1` | 几何年化；不能把现有均值复利估计列改名 CAGR |
| 波动 | 相邻总回报日收益的样本标准差 × √252 | 百分数；同一完整窗口至少 200/600/1,000 点；不足写 null |
| 最大回撤 | `max(1 − 值/截至当时最高值)` | 正数表示回撤深度；与收益用同一净值口径和日期 |
| 20 日均成交额 | 最近 20 个有效交易日成交额之和 / 20 | 必须 20 个值均已知，不能把缺失当零；停牌零成交是已知零 |
| 折溢价 | `(市场收盘价/单位净值 − 1) × 100` | 仅交易日和 NAV 日相同、且价格明确是收盘才计算；推断交易日期的盘中快照、异日 NAV、QDII 尚未披露均为 null |

价格小曲线优先最近 60 个收盘；没有市场历史但有已核验净值时显示净值曲线，并在列标题/提示明确。货币型无有效价格净值序列时保持空，不生成水平假曲线。

不纳入第一期：实时报价差、盘口深度、IOPV、精确跟踪误差、当前资金净流入、申赎套利空间、未经核验的跟踪指数 ID。小额同类组比较必须显示样本数；本期不要求计算 ETF 全市场百分位。

## 采集、存储和 API

与 [16 · 选股](./16-STOCK-SCREENING.md) 共用 `selection_*` 独立表和 `fetch:selection` CLI：

- 目录/身份/分类及其依据，与每日行情/物化筛选指标分开。目录覆盖不等于某项指标有效覆盖。
- 日 K 独立保存 `asset_type + symbol + adjust + trade_date`，ETF `adjust=none`，股票 `forward`；禁止混入现有无复权字段的 `market_daily_bar`。
- ETF NAV 保存 `unit_nav`、`adj_nav` 及各自日期；财报/profile 原始响应可用于审计，但只读 API 只返回所需 DTO，不能回传凭据或完整原始大响应。
- 列表指标在 CLI 物化，API 不能每次扫描 3,000 万净值，也不在用户点击时调用扶摇。历史最多返回所选 1/3/5 年，日/周/月聚合复用 `aggregateMarketBars`。
- `selection_collection_status` 保存每类任务最近成功、最近尝试、失败摘要、目录数量、行情/净值/历史实际数量。状态与数据一起事务发布，失败不覆盖上次成功数据或时间。
- **研究目录不能复用宏观的 `is_active` 作为唯一资格**。`publishMarketCollection.replaceWatchlist` 会禁用不在小观察池的标的；新增 1,670 只目录也不能把宏观 ETF 观察区扩大成全市场表格。新采集不修改宏观观察池定义。
- 老基金备份可继续恢复；独立迁移幂等。生产 API 只读，缺表返回 `ready:false`，不在请求里创建表。

初始策略：全目录 + 全部严格核验本地资料；额外深采最多 60 只 ETF，包括原 8 只宏观 ETF、510300/510310/159919 的同方向比较、513100/511010 等跨资产样本，其余按各资产类已知披露规模排序轮取。该选择是可复现的研究池规则，不称全市场最优；具体成功数量采集后回填。每只深采快照、五年真实日 K、五年 NAV、profile、披露规模和持仓。单只失败保留其余可用内容，标明缺项。

扶摇请求串行、间隔至少 400ms，有限重试（3 次），校验 HTTP、`code===0`、证券身份、日期与 OHLC。API key 只读环境，日志不可含请求头；不能网络失败后悄悄退回证据模式。CLI 提供 `--etf-limit`、`--stock-limit`、`--symbols` 等有界补采入口、`--scope etf|stock|all` 和 `--watch`；具体参数实现后写 [03 · 脚本](./03-SCRIPTS.md)。

同一采集源禁止并行运行两份 collector；网络读取与 SQLite 发布分开，短事务落库。常规每日收盘后刷新目录/快照/所选池历史/NAV，资料与财报可按周或报告期补采。网页定时刷新只是重读缓存，不能宣称已启用常驻采集；实际维护方式在验收记录里说明。

| 只读 API | 职责 |
|---|---|
| `GET /api/selection/etfs` | 参数同列表，返回 rows、page/total、coverage、categories、统一来源时间、筛选说明 |
| `GET /api/selection/etfs/:symbol` | 独立 ETF 资料与覆盖、费用/规模/NAV/风险、披露持仓、基金链接 |
| `GET /api/selection/etfs/:symbol/bars?years=1&interval=day` | 真实 OHLC、`adjust:none`、实际首末日和是否覆盖完整窗口 |

查询继承登录保护，并在一次只读事务内完成。无标的 404；标的存在但无 K 为 200 + 空 bars/原因；旧库为可解释的未就绪。请求错误不能伪装 0 个筛选结果。

## Basalt 与验收

复用 `ResearchHeader/LayerCard/PanelHeading`、Basalt Button/Select/Input/Tooltip、现有表格排版和字体 token。主内容宽、筛选紧凑，列表曲线放行内；顶部最多一行简洁统计，避免大号无内容卡片挤掉比较表。来源和时间在页头统一展示，字段口径集中在 i；报告期列属于比较必需数据，允许保留。

详情以大 K 为视觉主体，桌面主图约占主内容三分之二宽、至少 440px 高，旁边放紧凑产品/风险摘要，下方费用规模和披露持仓填满布局。默认一年，可切三年、五年和日/周/月；缺 OHLC 时清楚显示不可用，不用 NAV 拼蜡烛。延续当前涨跌色偏好，深浅主题、hover 字、键盘焦点和窄屏都可读。

必须验证：未核验基金关联不回填、异日折溢价为空、费用 null 与 0 不混、持仓报告期不冒充当前、窗口不足不算五年、排序 null 最后、筛选 URL 与详情返回、缺表/错误/空态、K 线真实及日周月聚合、宏观观察池不被改变。测试用自建小样本，不提交生产数据；完成仓库类型、lint、核心/API/Web 测试及构建后进行真实浏览器 review。
