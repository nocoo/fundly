> 本地实现日期：2026-09-06。调研与来源证据见 [13 · 宏观大屏与跨资产数据调研](./13-MACRO-DASHBOARD.md)。代码已随 v0.5.0 部署到 Railway，CI 和部署成功，线上 `/api/live` 已确认版本 0.5.0。生产 Volume 数据需要单独采集/同步，发布代码不会自动复制本地 SQLite。

## 页面与下钻

入口为 `/market`，本地预览为 <https://fundly.dev.hexly.ai/market>。页面沿用 Basalt 2.0.3 的应用外壳、按钮、卡片、表格、弹窗和主题。大屏模式收起导航：顶部为主要指数，左侧为紧凑的沪深广度和带行内收盘价曲线的行业列表，中央为可切换标的的大 K 线，右侧为跨资产摘要。三栏填满剩余高度；窄屏优先展示主图并纵向滚动。ETF 产品表移至「ETF 研究」弹窗和行业关联入口。

| 层次 | 当前覆盖 | 下钻内容 |
|---|---|---|
| 大盘 | 上证、深证成指、沪深300、创业板、中证500、中证1000、科创50 | 1 / 3 / 5 年真实 K 线、OHLC 与成交量 |
| 沪深广度 | 目录核验后的沪深 A 股有效样本 | 涨跌平、中位涨跌、成交额、涨停 / 跌停 / 炸板 |
| 行业观察池 | 半导体、银行、贵金属、软件开发、汽车整车、电力、白酒 | 行内近 24 个交易日收盘价曲线、点选进入大 K 线、活跃成分、全部成分、主题关联 ETF |
| ETF | 510300、588000、512480、512800、513100、518880、511010、159915 | 独立日 K、市价与净值、同日折溢价、资料、披露持仓、已有基金档案 |
| 跨资产 | 23 个指标，概览精选其中 14 个 | 商品 / VIX 日 K；汇率、利率、原油现货和海外股指的观测历史表 |

行业是**代表观察池**，不宣称为同级、互斥的完整行业分类。三组行业与 ETF 关系明确标为主题关联；黄金 ETF 不等于黄金股指数。ETF 与已有基金的链接通过源目录 / 资料及本地基金名称核验，不能仅凭六位代码或相似名称建立。

标的、时间范围、K 线周期写入 `instrument`、`years`、`interval` 查询参数；行业选择兼容 `industry`。默认沪深300、1 年日 K；3 年默认周 K、5 年默认月 K，支持手动选择日 / 周 / 月 K。快速连续切换会合并待生效参数，避免覆盖刚选的范围。从 ETF 进入基金档案后可回到原标的和时间范围。基金档案会根据已核验关联默认展示真实场内 K 线，也可切回净值与基准；反向入口「放入宏观视野」携带所选标的、年份与周期。`wall=1` 可直接打开大屏模式。

## 行情口径

K 线只使用上游真实开、高、低、收数据。没有 OHLC 的日度序列以数值表展示，不将收盘值复制成四价，不伪造分钟图。成交量缺失与零值分开；VIX 没有成交量。上期所历史固定为所选合约，不能把各日主力拼成未经处理的连续合约。

| 来源 | 数据与频率 | 当前边界 |
|---|---|---|
| 扶摇 Financial-API | 指数、行业、ETF、A 股快照；日 K；基金披露 | 已验证闭市 / 日频数据，尚未在交易时段验证实时延迟 |
| 上期所 | 沪金、沪铜指定合约日行情 | 涨跌相对昨结算；收盘、当日结算、昨结算、持仓量分别保存 |
| Cboe | VIX 真实日 OHLC | 无成交量 |
| ECB | 美元 / 人民币、美元 / 日元日度参考汇率 | 由同源同日 EUR 基准交叉计算，不是可成交报价 |
| 中国货币网 | Shibor 8 个期限、LPR 1 年及 5 年以上 | Shibor 日频、LPR 月频；利率变化用 bp |
| FRED | 美债 10 年 / 2 年及同日利差、WTI / Brent 现货、广义美元、标普500、纳指综合 | 保留各序列自己的观察日；广义美元不是 DXY，现货原油不是期货 |

页头统一展示最近成功采集时间，卡片不重复显示来源和采集时间；小「i」可展开来源、该项行情 / 观察日期和独立采集时间，完整状态仍在「数据状态」中。统一采集时间不等于所有市场的统一行情日期。披露持仓另外保留报告期和公告日。资料接口没有公告时间时返回空值。最新净值即使落后于市价也仍显示实际日期，只有二者同日且数值有效才计算折溢价。持仓数量按实际披露展示，债券 ETF 不称作“前十大股票”。

日线按最后一个实际交易日向前取 1 / 3 / 5 个日历年，闰日按月底对齐。周 K 以周一分组，月 K 按自然月分组：首个开盘、最高价最大值、最低价最小值、末个收盘，日期为最后一个实际交易日。首尾周期按窗口中可见交易日聚合。任一成员日缺失成交量 / 成交额时，该周期相应总量为空，零值仍为零。区间涨跌按首末日收盘计算，不随日 / 周 / 月切换而变化。图下显示实际覆盖区间与日线数量；固定期货合约历史不足五年时明确标注「可用历史」。

API 继续保留 20 / 60 交易日行业收益与超额字段，分别需要 21 / 61 个收盘点；这些短期指标不占用大屏主图。

## 采集入口

运行时为 Bun + 原生 `fetch` + `bun:sqlite`。扶摇密钥来自服务端环境变量 `HITHINK_FINANCE_API_KEY`；本机已保存到 Git 忽略的根 `.env`（权限 600），Bun 自动读取。密钥不进入 `VITE_*`、浏览器请求、API 响应或文档。

```bash
# 一次刷新全部已支持来源；默认数据库 data/fundly.db，历史窗口 1826 日
bun run fetch:macro

# 只更新扶摇及上期所
bun run fetch:macro --sources fuyao,shfe

# 持续更新；先采集一次，再于每轮完成后等待 60 分钟
bun run fetch:macro --watch --interval-minutes 60

# 独立测试库与历史回补窗口（90–3650 个日历日，上游实际可用范围可能更短）
bun run fetch:macro --sqlite /path/to/fundly.db --history-days 1826

# 显式导入已有证据；网络失败绝不会自动切换到该模式
bun run fetch:macro --offline --evidence-dir output/macro-research-2026-09-06/evidence
```

支持来源名：`fuyao,shfe,cboe,ecb,shibor,lpr,fred`。持续更新间隔允许 15–1440 分钟；不接受离线证据模式。`Ctrl+C` / `SIGTERM` 会在当前批次完成后退出。当前交付没有安装系统定时任务，也没有在 Railway 启动采集进程；需要持续更新时启动上面的 `--watch` 命令。可见页面每分钟同步总览与当前标的 K 线，“刷新”可立即同步；两者均只读取本地缓存，不触发上游采集。

同一数据库的采集器通过旁路 SQLite 排他锁防止重入，锁文件为 `<sqlite>.macro.lock`，进程退出或崩溃后操作系统自动释放锁。网络采集期间不锁住基金主库。不同数据库可以独立采集。

扶摇请求按至少 400ms 间隔串行执行，设置超时与有限重试。认证、参数及业务错误不会无限重试。只有已存最早日期覆盖请求窗口时才跳过老日线，保留五天重叠修正；扩大窗口会触发历史回补。ETF 历史按不超过 1460 日的窗口分段，避免上游单次五年限制；上期所仍按固定合约补足 61 个交易日，不拼接不同合约。

2026-09-06 实测发现：请求从 2021-08-11 开始时，部分扶摇端点返回空历史；改从 2021-09-04 开始则取得五年日线。因此默认历史窗口设为 1826 日，不能仅凭接口文档宣称十年全部可用。

市场模块新增 12 张独立表：标的、别名、最新快照、真实日 K、单值观测、成分、关系、广度、来源状态、采集批次、ETF 资料、ETF 披露持仓。`initMarketSchema` 幂等执行，基金核心 schema 仍为 3；不改写已有净值、基金业绩或精选指标。旧备份没有市场表时，API 返回未就绪 / 404，采集 CLI 会补建市场表。

A 股分页以核验后的目录代码集合为准，检查每页总数、长度、重复与缺失。数据先在内存组批，通过验证后以一个事务发布该来源的元数据、行情、日线、观测值、广度、披露和成功状态。任一发布步骤失败即回滚；独立记录错误并保留上次成功数据。可选披露缺失记录为部分成功，不将缺失填零。

每个市场 API 请求使用独立只读连接和读事务，避免多个 SQL 查询横跨一次发布。以下路由全部沿用现有登录认证：

| 路由 | 返回 |
|---|---|
| `GET /api/market/overview` | 指数、广度、行业（含最近 24 根 OHLC）、ETF、跨资产卡片和来源状态 |
| `GET /api/market/bars/:id?years=5&interval=month` | 日历年窗口与日 / 周 / 月 K，实际覆盖范围、原始交易日数量和区间涨跌 |
| `GET /api/market/bars/:id?limit=60` | 兼容条数查询：日 K，按日期升序；含价格及成交量单位 |
| `GET /api/market/series/:id?limit=60` | 观测值、日期、公布时间及来源 |
| `GET /api/market/industries/:id/constituents` | 当前成分及最新行情 |
| `GET /api/market/etfs/:id` | 行情、净值、资料、披露持仓、基金链接 |

`:id` 是完整规范 ID，例如 `index:000001.SH`、`industry:881155.TI`、`etf:510300.SH`，URL 使用 `encodeURIComponent`。`limit` 查询保留 1000 条上限，非数值使用默认 60；`years` 必须为 1、3、5，`interval` 必须为 day、week、month。年限查询不受 1000 根上限截断，非法范围返回 400。浏览 API 不迁移数据库、不采集上游、不写行情。
