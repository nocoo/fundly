# 16 · 选股：估值、经营质量与价格风险

> 2026-09-06 规划；与 [15 · 选 ETF](./15-ETF-SCREENING.md) 共用采集与研究页面骨架。直接在 `main` 原子提交；主 agent 负责 API 核验和 review，通过 Herdr 调度旁边 pi 实现。

## 目标与覆盖分层

宏观 → 行业 → 企业的研究链，需要区分价格便宜、经营稳健、增长可持续和现金回收。选股以这些问题拆页面，使用可解释的硬条件，不输出买卖信号或统一打分。

第一期全 A 股目录和快照支持浏览，批量估值支持全目录筛选；财务与五年价格历史使用有界研究池，界面明确「深度研究覆盖 n / 目录 N」。不能用研究池分母宣称全 A 股财务排名。未深采的股票也能检索并打开基础详情，展示真实已有快照和估值及缺少的内容。

初始深采最多 80 只：强制包含 600519.SH、000001.SZ、300750.SZ、688981.SH、601398.SH；从可用行业成分中按有效成交额轮取代表，再按全市场成交额补齐，去重、记录规则与组成。行业成分可先复用宏观已采七个行业，扩充同花顺行业目录时逐行业请求并记录成功范围。行业缺失显示「未分类」，不根据名称猜上市公司行业。

选股组默认只展开当前导航分组。基础过滤：`q/exchange/industry/coverage/years/sort/order/page`，每页 50。默认选股沪深 A 股，浏览可选北交所/全部；未知行业保留单独选项。经营类筛选页默认排除已识别金融业，允许切到金融业专属比较；精选默认剔除名称明确 ST/*ST 的股票，开关与识别依据可见，不能说成完整交易状态识别。

启用数值门槛时 null 不通过；未启用时保留 null 并置于排序末尾。负 PE/PB/PS/PCF 在基础详情可显示原值，但不进入低估值候选。所有排序/阈值白名单、finite 校验与范围钳制；切筛选归第一页。不同 lens 列与默认条件实际不同，不能仅改标题复制相同涨跌表。

财务期固定使用最新**完整年报**进行可比较筛选，顶部说明「年度口径」，每行显示年份。筛选支持指定共同财报年；不同年报不能无提示混排。半年报已验证但本期不计算 TTM/单季增长；后续加入需确认季度接口是累计还是单季，按同一会计期间对齐。

## 财务字段与公式

按 `thscode + period_end_ms` 对齐三张表，选择同报告期最近披露的修订值。保留 `report_date_ms`（可能是后来重述的日期）、币种和期末，不能说成最早公告或可用于无前视回测。API 无历史公告快照，五年趋势是当前可获得的重述后数据。

`indicators` 专用 envelope 适配器复用 MarketReader 的 HTTP/业务码/安全处理，不强行套 `data.item`。字符串数字严格转换，null/空串不能为 0。以下值来自已实测 `index_id`；百分数原值 32.53 就是 32.53%，不再乘 100。

| 显示指标 | 来源 / 公式 |
|---|---|
| 加权 ROE | `index_weighted_avg_roe` |
| 扣非加权 ROE | `index_deduct_weighted_avg_roe` |
| 毛利率 | `sale_gross_margin`，银行可能 null |
| 净利率 | `sale_net_interest_ratio`，此 ID 对应销售净利率，不能翻成净息差 |
| 资产负债率 | `assets_debt_ratio`；或已对齐 `total_debt / assets_total * 100`，`total_debt` 是负债合计，不能叫有息负债 |
| 营收同比 | 最新完整年 `operating_income / 上一完整年值 − 1`；上一年必须正、会计年度连续 |
| 归母净利润同比 | `parent_holder_net_profit / 上年值 − 1`；上一年非正时不计算百分比，可展示扭亏/转亏事实 |
| 营收/归母净利润三年 CAGR | `最新年值 / 三年前值` 的 1/3 次方减 1；四个会计年度连续且相应值为正，否则 null |
| 经营现金流 | `act_cash_flow_net`，原始货币单位，CNY 显示亿元 |
| 现金利润比 | `act_cash_flow_net / net_profit`；净利润非正则 null；同比较用合并净利润，不混入归母值 |
| 资本开支 | `pay_fixed_assets_etc_cash`；仅明确的购建固定资产等现金支出 |
| 经营现金流减资本开支 | 上述两项之差；列名直写口径，不声称完整 FCFF/企业自由现金流 |

金融业的经营现金流、负债率与一般企业不直接可比。银行/证券/保险当前行业成员可标记金融业；现金质量页默认排除，且金融股的相关通用阈值不参与「通过」判定。金融股仍支持 PE/PB、加权 ROE、净利增长；不提供尚无数据的净息差、不良率、拨备覆盖率或资本充足率。

## 价格与估值口径

- 最新快照为原始市场价格，历史 K 为 `adjust=forward`，图旁明确「前复权」。它适合观察连续价格趋势，不宣称含所有现金流的投资组合总回报。
- 1/3/5 年窗口、样本数、年化波动与正数最大回撤规则同文档 15；价格日收益基于同一份前复权 close。20/60 日需 21/61 个有效点。均线偏离 `(最新前复权价/最近60日均价−1)*100`，不足则 null。
- 复权历史会因企业行动整体修订。该有界池每次更新重新取得五年完整前复权窗口，并在单事务替换，不能只追加最后几日；完成前保留上一整份历史。
- 周/月 K 由日 K 聚合：第一 open、最高 high、最低 low、末日 close；volume 或 turnover 缺任一天则该聚合量为 null。不混合不同复权口径。
- 高分红股票的前复权历史可能出现非正价格，保留上游有限且几何关系正确的原值，不夹到零。2026-09-06 实测 `600066.SH` 在 2022-04-27 的未复权 OHLC 为 7.18/7.43/6.90/7.36，前复权为 0.18/0.43/-0.10/0.36，四价均下移 7 元。该负低点可以画 K；若所选窗口含非正收盘价，则百分比收益、年化和回撤均不可计算，不能跳过这些点再给出数值。
- 估值是当前快照而非历史估值分位；PE TTM 与 PB MRQ 明示。上游顶层 timestamp 是批内最新有效时间，不代表每个指标同时计算，不伪造逐字段时刻。
- 停牌、IPO 历史不足、接口缺数都以覆盖状态表达，不能填 0 或随机趋势。暂无上市天数/流通市值时不提供相应筛选。

## 存储、更新和 API

共同表和发布约束见文档 15。股票增加按代码、报表类型、会计期、披露日保存的财报原文与标准字段；指标 materialize 成独立筛选快照。所有金融计算为不含 I/O 的纯函数，数据库处理、网络适配和 React 分层。

全目录估值每批至多 100 codes，集合检查重复、漏项与错 symbol；完整基本批次验证后事务发布。深采分标的处理失败，保留其最近成功并附真实日期，不能把旧财报/旧 K 标成刚刚更新。筛选需要同时返回目录数、某维度有效数、当前过滤后数量；失效/未知值不算有效样本。

| 只读 API | 职责 |
|---|---|
| `GET /api/selection/stocks` | 专业 lens 筛选、稳定排序、分页、行业/交易所/财年可选项、覆盖与时间 |
| `GET /api/selection/stocks/:symbol` | 行情估值、已采财报趋势、指标口径、缺失与已知行业 |
| `GET /api/selection/stocks/:symbol/bars?years=1&interval=day` | 前复权真实 OHLC，实际起止、adjust、有效覆盖 |

只读 snapshot 事务、鉴权、旧库/404/无历史/上游失败区别同文档 15；HTTP 请求不能自动网络补采。页面刷新只读缓存；CLI 的日频任务由维护者运行或部署调度，本次交付要写出实际启用状态。源限流失败以摘要记录，不暴露 key，不自动无限重试。
